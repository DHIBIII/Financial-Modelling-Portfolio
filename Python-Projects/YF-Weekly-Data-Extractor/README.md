# Automated NSE Stock Data Extraction using Python

## Overview

This project automates the extraction of weekly historical stock price data from Yahoo Finance using Python. Supports downloading historical data for any NSE-listed company.

The extracted data is exported to Excel for use in financial modeling, valuation, and equity research.

## Objective

- Automate stock market data collection
- Export clean datasets to Excel
- Prepare data for financial analysis

## Technologies Used

- Python
- yfinance
- pandas
- openpyxl

## Files Included

- `yf_weekly_data_extractor.py` – Python script
- `HUL_Weekly_24Jul2024_24Jul2026.xlsx` – Sample output for Hindustan Unilever
- `NIFTY50_Weekly_24Jul2024_24Jul2026.xlsx` – Sample output for NIFTY 50
